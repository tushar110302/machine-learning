## 🎯 Learning Approach

For most algorithms, I aim to:

1. Understand the underlying mathematics and intuition.
2. Implement the algorithm from scratch using Python and NumPy.
3. Test it on a dataset.
4. Compare my implementation with `scikit-learn` where appropriate.
5. Document what I learned and the results.
